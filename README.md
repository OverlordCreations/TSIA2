# TSIA2

Public TSIA2 math practice site: https://overlordcreations.github.io/TSIA2/

The current publication is an owner-authorized evaluation build for trying the complete practice experience on Chromebooks and other computers. It is not a claim of completed instructional approval. Practice history stays in the current browser; sign-in, cross-device saving, and live teacher monitoring are disabled.

The searchable guide is at https://overlordcreations.github.io/TSIA2/help.html.

This repository contains only browser-deliverable files and deployment configuration. Private instructional sources, research, review records, credentials, and student records are not published. The deployment workflow verifies the exact generated file list and file hashes before uploading the site.
