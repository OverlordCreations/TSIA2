Getting startedOpen topic

How do I begin?

When practice is available, choose a math area from the progress page. Start with the question in front of you. You only need to answer one question at a time.

Choose the answer that makes the most sense to you, then read the message that appears. Use Continue for the next step or Back to progress when you want to choose a different area.

If the page says practice is being prepared, check that you used the current link from your teacher. You can still read this guide while practice is unavailable.

Answers, next steps, and hintsOpen topic

What happens after I answer?

You will get a short message about the answer and a next step. A correct answer may lead to a new kind of question. A wrong answer may lead to another chance with the same idea or a smaller step that helps first.

A wrong answer is useful practice information, not a reason to quit. Read the explanation, try the next question, and ask your teacher for help if you are stuck.

How do hints work?

Select Show me a small step when you need a nudge. The practice can show up to three small steps. Read one step, try the problem yourself, and use another step only if you still need it.

Hints are help, not a penalty. The progress page can show that a question was completed with help, so it is okay to use them honestly.

The four math areasOpen topic

Which topics can I practice?

  • Quantitative Reasoning (QR): percents, ratios, rates, and proportional reasoning.
  • Algebraic Reasoning (AR): equations, functions, exponents, and exponential relationships.
  • Geometric and Spatial Reasoning (GSR): area, volume, right triangles, and visual math supports.
  • Probabilistic and Statistical Reasoning (PSR): data, chance, and statistics.

The progress page shows one card for each area. Pick an area to begin there, or use the suggested next step when one is shown.

Understanding progressOpen topic

What do the skill labels mean?

  • Not Assessed: you have not answered enough questions in that skill yet.
  • Emerging: you have started showing what you know.
  • Developing: you are building the skill with more practice.
  • Near Mastery: you are close and may see another question that checks the idea in a new situation.
  • Mastered: your recent work has met this practice site's current goal for that skill.

These labels describe practice in this site. They are not a test score, course grade, or prediction of an official TSIA2 result.

The recent-progress view is a short snapshot of the questions you have tried in this browser. It may not show every skill or every part of your learning, so use it as a guide for what to practice next.

Saving, reloading, and changing devicesOpen topic

Will my work stay when I reload?

After the practice page has loaded, it saves your practice in this browser on this device. Closing and reopening the same browser on the same device can continue compatible saved work.

Do not clear browser data for this site if you want to keep that local history. If the browser blocks storage, practice may last only until the tab closes.

What if I use another computer?

A different computer, tablet, Chromebook profile, or browser starts with fresh history. Cross-device saving is not available yet. If you need to continue on another device, keep a note of the topic you were practicing and begin there again.

Sign-in, classes, and teacher monitoringOpen topic

Can I sign in or join a class?

Not yet. Sign-in and class connection are currently unavailable in this evaluation build. You do not need an account to read this guide.

Teacher monitoring and class reports are not active right now. Do not assume that a teacher can see your practice history from this build. Follow your teacher's directions for sharing questions or asking for help.

Calculator, Chromebook, and access helpOpen topic

May I use a calculator?

Read the note below each question. It will tell you whether a calculator is not required, may be used if your teacher allows it, or should be used if one is available. Follow your teacher's rules.

Can I use a Chromebook?

Yes. Use a current Chrome browser, make sure JavaScript is turned on, and use the normal browser zoom if text is too small. The buttons and help topics work with a keyboard: use Tab to move, Enter or Space to open a topic or choose a button, and the visible focus outline to see where you are.

On a small phone-sized screen, the guide stacks into one column. You can use the search box or the category links instead of scrolling through everything.

Privacy and troubleshootingOpen topic

What personal information should I enter?

This evaluation guide does not ask for your name. Do not type your name, email address, password, class code, or other personal information into a practice answer or a help search.

The page will not load. What should I try?

  1. Check that you have an internet connection for the first page load.
  2. Reload the page, then choose the retry button if it appears.
  3. Use a current browser and make sure JavaScript is enabled.
  4. Try a private or school-approved browser profile if extensions block the page.
  5. Ask your teacher or school technology staff for help if the problem continues.

Never share a password or another student's information while getting help.

Evaluation statusOpen topic

What is the current status of this site?

This public evaluation build lets teachers try 720 questions across 89 skills on different computers. Formal content review is not completed, so it is for trying the experience and finding problems, not assigning an official score.

You can practice without signing in. Each computer keeps its own practice history; this version does not send that history to a teacher or move it between computers.
